# Definition of done

This skill is done for the current cycle only when all of the following are true:
- the active phase is explicitly identified
- the chosen slice is narrow and concrete
- the correct implementation skill is selected
- the validation plan is explicit
- the done condition is explicit
- the next recommended slice is singular, not a menu

This skill is not done if it outputs a vague plan like “improve testing” or “harden the API.”
