# When to use

Use this skill when:
- starting a new work session
- the repo state is unclear
- multiple tasks seem possible and prioritization is needed
- deciding whether a phase is complete
- selecting the next execution slice
- checking whether a requested task is premature

Use this skill before any other skill at the beginning of a session.

Do not use it as a replacement for implementation skills. Once the slice is chosen, switch to the skill that owns the actual work.
