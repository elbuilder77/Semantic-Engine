# Checklist

- Read `ROADMAP.md` completely.
- Read `TASKS.md` completely.
- Inspect the current repo structure.
- Identify critical files tied to the active phase.
- Determine whether the repo is in Phase 1, 2, 3, or 4.
- Check if any earlier phase gate is still open.
- Select one primary skill.
- Select at most one secondary skill.
- Define one narrow execution slice.
- State the validation method before implementation begins.
- State the done condition.
- State the single next recommended slice.
