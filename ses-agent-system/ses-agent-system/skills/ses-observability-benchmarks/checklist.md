# Checklist

- Define exactly what is being measured.
- Define the workload or dataset.
- Define success metrics before running anything.
- Confirm the measurement path is reproducible.
- Add or update instrumentation for latency/errors/empty responses.
- Separate microbenchmarks from end-to-end measurements.
- Record hardware/environment assumptions if relevant.
- Avoid vanity metrics.
- Tie the result to a concrete engineering decision.
