# Purpose

Use this skill to harden the SES core against security, correctness, and operability failures.

This skill owns work related to:
- authentication integrity
- API key handling
- HMAC-related request/response safety
- rate limiting behavior
- fail-open vs fail-closed policy
- secret/config handling
- prevention of sensitive identifier leaks

## Core responsibility

Make the default runtime behavior safe under normal operation and predictable under failure.
