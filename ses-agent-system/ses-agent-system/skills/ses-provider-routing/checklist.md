# Checklist

- Identify the current provider selection logic.
- Identify all configured providers.
- Define the fallback order.
- Define timeout and retry behavior.
- Define how provider errors are normalized.
- Decide what counts as an unacceptable provider response.
- Add tests for provider failure and fallback.
- Add metrics/logging hooks for provider-level behavior.
- Update documentation for provider config and expected runtime behavior.
