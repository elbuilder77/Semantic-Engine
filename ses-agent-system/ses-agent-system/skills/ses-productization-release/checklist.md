# Checklist

- Verify README matches the actual product and runtime.
- Verify quickstart commands still work.
- Verify env/config docs are sufficient.
- Define the packaging stance explicitly.
- Ensure CI covers at least lint/build/test or document the gap.
- Check local vs Docker parity for the current critical flow.
- Check dashboard/spotlight/widget language and contracts for drift.
- Add troubleshooting notes for the most likely failures.
- Record what is release-ready vs still provisional.
