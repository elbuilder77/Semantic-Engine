# Purpose

Use this skill to make SES answers trustworthy, traceable, and exportable.

This skill owns:
- source traceability across the RAG flow
- consistency between answer text and cited evidence
- empty-answer handling
- output fidelity for answer export
- the product promise that answers are immediate, grounded, and auditable

## Core responsibility

Ensure every generated answer has a defensible relationship to retrievable source evidence.
