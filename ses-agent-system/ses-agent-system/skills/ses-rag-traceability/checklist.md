# Checklist

- Trace the path from retrieval to final answer.
- Identify where source metadata is created, transformed, or dropped.
- Verify the answer payload preserves enough source information.
- Verify export flows preserve the same evidence model.
- Define behavior for zero-result and weak-result cases.
- Add tests for grounded answers.
- Add tests for empty-answer or no-evidence paths.
- Check whether formatting changes distort source mapping.
- Record any unresolved ambiguity in source attribution.
