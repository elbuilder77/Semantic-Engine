# AI Agent Universal Kernel

This directory is an "Operating System" for AI Coding Agents (like Cursor, Cline, Pi, etc.). It forces the AI to behave as a disciplined, execution-oriented engineer rather than a conversational assistant.

## How to use

1. Copy this `ai-agent-kernel` folder into the root of any new or existing project.
2. Instruct your AI agent to read the `AGENTS.md` file (or just open the agent within this directory so it reads it automatically as context).
3. Call specific skills when needed (e.g., "Use the roadmap-executor skill to process our TODO.md").

## Structure

- `AGENTS.md`: The core mandate and behavioral rules for the AI.
- `skills/`: Specialized SOPs (Standard Operating Procedures) for the AI to follow during specific tasks.
