Quickstart in 3 Simple Steps

Get up and running with SES Core in under a minute.

01

Install Library or CLI

Install the lightweight core library with built-in CLI tool in your environment.

Terminal
$ pip install ses-core
02

Index Documents or Mount Folders

Mount any directory for instant descriptor streaming and automatic background change detection.

Terminal / Python
$ ses mount /data/docs --namespace legal
03

Execute Semantic Searches

Query dense vectors with PyO3 Rust cosine re-ranking and optional local LLM synthesis.

Terminal / Python
$ ses search "liability clause" --namespace legal

Polyglot Integration in 3 Lines of Code

Integrate search and offline RAG into your stack in your language of choice.

TypeScript / Node.js 
import { SemanticEngineClient } from "@ses-ai/client";

const client = new SemanticEngineClient({
  baseUrl: "http://localhost:8000",
  apiKey: process.env.SES_API_KEY!,
});

const { answer, results } = await client.search({
  namespace: "contracts",
  query: "What is the liability limitation clause?",
  generateAnswer: true,
});
Go 
import (
    "context"
    ses "github.com/elbuilder77/Semantic-Engine/sdk/go"
)

client, _ := ses.NewClient(ses.ClientConfig{
    BaseURL: "http://localhost:8000",
    APIKey:  "your_api_key",
})

resp, _ := client.Search(context.Background(), ses.SearchRequest{
    Namespace:      "contracts",
    Query:          "termination conditions",
    GenerateAnswer: true,
})
Python (Simplified Aliases) 
import ses

# 1-Line Mount Mode Indexing
await ses.mount("/data/docs", namespace="legal")

# 1-Line Semantic Search with Rust PyO3
results = await ses.search(
    query="termination conditions",
    namespace="legal",
    top_k=5
)
